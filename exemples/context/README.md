# Modèles de contexte prêts à l'emploi

Ce dossier contient des exemples de fichiers que vous pouvez copier-coller dans un dossier `context/` à côté de votre vidéo pour personnaliser la transcription.

1. Créez un dossier nommé `context` dans votre projet.
2. Copiez les fichiers dont vous avez besoin :
   - `glossaire.yaml` : pour vos mots clés et noms de produits
   - `participants.yaml` : pour donner les prénoms des personnes qui parlent
   - `acronymes.yaml` : pour expliciter les sigles de votre entreprise
   - `zones-sensibles.yaml` : pour indiquer les éléments confidentiels à flouter
3. Modifiez-les avec n'importe quel éditeur de texte.
